Novelite v1.0.1 brings native macOS downloads for Apple Silicon (M-series).

## 下载 / Downloads

- Apple Silicon（M1/M2/M3/M4 等）：`novelite_1.0.1_aarch64.dmg`
- **Intel Mac：暂不提供安装包 / No Intel Mac installer is provided.**
- Windows：`*-setup.exe` 或 `.msi`
- Linux：`.deb` 或 `.AppImage`
- `SHA256SUMS.txt` 提供所有安装包的校验值。

## macOS 安装

支持 macOS 11 及以上，并需 Safari/WebKit 16.4+；旧系统请先安装 Safari 更新。打开 DMG，将 Novelite 拖入「应用程序」。
此版本采用 ad-hoc 签名，未经 Apple 公证。首次打开如被拦截，在「系统设置 → 隐私与安全性」中为 Novelite 选择「仍要打开」，然后再次确认打开。
无需关闭 Gatekeeper 或系统整体安全设置。

macOS 11 or later with Safari/WebKit 16.4+. Install Safari updates on older systems. Open the DMG and drag Novelite into Applications. This build is ad-hoc signed and **not notarized by Apple**. If the first launch is blocked, use **System Settings → Privacy & Security → Open Anyway** for Novelite.

## 更新内容

- 修复 Windows 专用依赖导致的 Mac 安装失败，补全跨平台依赖锁文件。
- 桌面端使用原生文件夹选择和保存对话框，支持本地目录读写与 TXT/Markdown 导出。
- 修复根目录章节与分卷混合时的文件归属；分卷改名保留其他文件，切换作品断开旧目录。
- 修复取消或失败的导出仍提示成功的问题。
- Mac 使用 `⌘⇧Z` 重做、`⌘⌥F` 替换；支持 Option 快捷键，避免输入法组词时误触命令。
- 修复显式保存仍等待自动保存计时器的问题，`⌘S`/`Ctrl+S` 立即持久化手稿。
- 修复快速切换章节时，延迟保存可能写入下一章的问题。
- 补齐桌面窗口控制权限；版本号与更新检查保持一致。
- 发布前检查 Chromium/WebKit、Apple Silicon 原生安装包、签名、DMG 完整性及启动进程；所有发布目标成功后统一公开。

## 验证范围 / Validation scope

自动化覆盖编辑、撤销/重做、保存后重启恢复，以及模拟原生 IPC 的文件操作；Mac CI 另检查真实应用签名、架构、磁盘映像和启动进程。原生文件对话框交互与所有 macOS 版本的完整人工验收尚未覆盖。

Automated checks cover editor workflows and native file operations with mocked IPC. macOS CI also verifies the real bundle, signature, architecture, DMG and process startup. Full manual testing of native dialogs and every supported macOS version is still pending.
