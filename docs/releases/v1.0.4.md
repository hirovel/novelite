# Novelite v1.0.4

提供 Windows x64 和 Apple Silicon Mac 独立应用。

## 升级时可靠保存手稿

- 修复 Mac 在快速安装更新并重启时，WebKit 本地存储尚未落盘、导致最后输入的文字回退的问题。
- 安装更新前，将手稿与应用设置写入原生磁盘快照；新版启动时先恢复数据，再打开编辑器。
- 磁盘保存失败会停止安装。恢复快照不会覆盖之后继续创作的新内容。

## 安装和更新

Mac：`brew tap hirovel/novelite https://github.com/hirovel/novelite.git && brew install --cask hirovel/novelite/novelite`

Windows PowerShell：`irm https://raw.githubusercontent.com/hirovel/novelite/main/install.ps1 | iex`

已安装用户可在应用内检查更新、安装并重启。Homebrew 更新命令为 `brew update && brew upgrade --cask --greedy hirovel/novelite/novelite`。

Mac v1.0.3 用户首次升级请先保存手稿、导出重要作品备份并关闭 Novelite，再执行上面的 Homebrew 更新命令（或用新版 DMG 替换应用）。旧客户端不包含本次新增的原生快照保护，快速应用内升级存在丢失最后输入的风险。v1.0.4 及之后的应用内更新会使用原生快照保护。

v1.0.2 及更早版本请先通过安装包或安装命令升级一次。MSI 用户继续使用 MSI 安装包。

Mac 使用临时签名，尚未经过 Apple 公证。首次启动如被系统拦截，请在“系统设置 → 隐私与安全”允许打开。

WinGet 是否可用取决于社区仓库合并和软件源同步，不由本次发布自动保证。
