# Novelite v1.0.3

提供 Windows x64 和 Apple Silicon Mac 独立应用。

## 自动更新

- 应用启动后及每 4 小时自动检查新版本，命令中心也可手动检查。
- 点击「安装并重启」后下载并校验签名，保存手稿，再安装重启。
- 下载、签名校验或保存失败会中止更新，保留应用和手稿，可重试。
- Windows EXE / MSI 分别更新为同类安装包，Mac 使用签名的应用更新包。
- 修正离线检查被误报为「已是最新版本」的问题。

v1.0.2 及更早版本需先使用安装命令或安装包升级一次，Windows MSI 用户请用新版 MSI 完成这次升级。此后可应用内更新。更新保留手稿和设置；重启后重新选择本地文件夹以恢复磁盘同步。

## 安装

Windows PowerShell：

```powershell
irm https://raw.githubusercontent.com/hirovel/novelite/main/install.ps1 | iex
```

Mac：

```bash
brew tap hirovel/novelite https://github.com/hirovel/novelite.git && brew install --cask hirovel/novelite/novelite
```

通过 Homebrew 更新：

```bash
brew update && brew upgrade --cask --greedy hirovel/novelite/novelite
```

Mac 需 Safari/WebKit 16.4+。应用采用 ad-hoc 签名，未经 Apple 公证；首次启动如被拦截，在「系统设置 → 隐私与安全性」选择「仍要打开」。

自动化验证覆盖双引擎编辑/保存回归、更新失败处理、原生包签名与篡改拒绝、Windows EXE/MSI 安装和启动、Mac DMG/Homebrew 安装和启动。两代带更新器正式版本之间的完整应用内升级仍需后续实机验证。
