Novelite v1.0.2 — 独立桌面 App，一行安装。

## Windows x64

在 PowerShell 中运行：

```powershell
irm https://raw.githubusercontent.com/hirovel/novelite/main/install.ps1 | iex
```

下载、SHA-256 校验和安装完成后，从开始菜单打开 Novelite。无需 Node.js。更新时重新运行此命令。也可下载下方的 `*-setup.exe` 或 `.msi`。需要 Windows 10/11 x64；安装器按需安装 WebView2 运行时。

## Apple Silicon Mac

已安装 Homebrew 的用户，在终端运行：

```bash
brew tap hirovel/novelite https://github.com/hirovel/novelite.git && brew install --cask hirovel/novelite/novelite
```

从「应用程序」打开 Novelite。升级：`brew update && brew upgrade --cask hirovel/novelite/novelite`。
也可下载下方的 `*_aarch64.dmg`。应用需要 macOS 11+ 和 Safari/WebKit 16.4+；Homebrew 自身的系统要求以其官网为准。

Mac 版采用 ad-hoc 签名，未经 Apple 公证。首次启动如被拦截，请在「系统设置 → 隐私与安全性」选择「仍要打开」。

## Changes

- 统一为独立桌面应用，移除 npm／浏览器启动器和安装失败后的浏览器回退。
- Windows 一行安装检查 SHA-256 和安装器退出状态；网络错误、校验失败或取消安装不再误报成功。
- 增加 Homebrew Cask，发布成功后自动更新版本和校验值。卸载保留手稿和设置。
- `npm run dev` 直接打开桌面窗口；npm 仅用于开发和构建。
- 发布前实际执行 Windows NSIS/MSI 安装、启动和卸载，以及 Mac Homebrew 安装、启动和卸载。

All downloads are standalone desktop apps. No Node.js or external browser is needed. Windows uses the system WebView2 runtime and macOS uses WebKit. Homebrew packages are ad-hoc signed, not notarized by Apple.

## Validation scope

自动验证覆盖编辑／保存回归、安装器失败处理、Windows 和 Homebrew 安装、应用进程启动、卸载、签名、DMG 完整性及下载校验。原生文件对话框的完整人工交互和各个系统版本仍需实机验收。

Automated checks cover editor regressions, bootstrap failure handling, Windows and Homebrew installation, native process startup, uninstall, signatures, DMG integrity and checksums. Full manual native-dialog interaction and every supported OS version remain outside this validation scope.
